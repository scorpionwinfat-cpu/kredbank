# KredBank Work visualization

Buildless public process visualization at /work/. Existing homepage and CNAME
are preserved. No accounts, credentials, customer records or private terms are
published. Lead parsing runs entirely in the visitor's browser with no network
requests. Role selection demonstrates future scenarios, not authentication.

Public news links retain bank/platform provenance. Bank route labels are a
model of the intended card, not proof of an active integration or live price.
Aggregates are a dated snapshot, not a connected dashboard.

Preview: python3 -m http.server 8765 --bind 127.0.0.1 from repository root.
Open http://127.0.0.1:8765/work/.
No build/dependency installation is needed. Publication uses this repository's
existing GitHub Pages route/domain; no new DNS or hosting account is required.
